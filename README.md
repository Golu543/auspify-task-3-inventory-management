# Task 3: Inventory Management System
**Auspify Technologies — Software Development Internship**

## Overview
A full-stack Inventory Management System built with React, Vite, Node.js, Express, and MySQL. It tracks product SKUs, stock quantities, reorder thresholds, supplier pricing, and ACID-compliant Stock-In / Stock-Out transactions with CSV reporting.

## Setup Instructions
1. Import `database/schema.sql` into MySQL 8.0.
2. In `backend/`, configure `.env` and run `npm install && npm start` (runs on port `5002`).
3. In `frontend/`, run `npm install && npm run dev` (runs on port `5175`).
